# 诊断输入数据格式与字段说明

## 单条带钢记录（诊断工具的输入）

一条带钢 = STRIPNO(可选) + 6个工艺参数 + 3段全长宽度曲线。批量场景为 CSV 文件（每行一条带钢），单条场景为 JSON 对象（字段相同）。

| 字段 | 含义 |
|------|------|
| STRIPNO | 带钢编号（可选，用于追溯） |
| FMWTARGETHOT | 精轧出口目标平均宽度热值 |
| RDWTARGETTOTAL | 粗轧出口目标平均宽度热值 |
| PDIWIDTHTOL | 带钢计划宽度余量 |
| FMWIDTHACTHOT | 精轧出口实际平均宽度热值 |
| RMWIDTHACTHOT | 粗轧出口实际平均宽度热值 |
| FMWTARGETCOL | 精轧出口目标平均宽度冷值 |
| RMDATASEQ | 粗轧阶段全长宽度数据（逗号分隔数值字符串） |
| FMDATASEQ | 精轧阶段全长宽度数据（逗号分隔数值字符串） |
| DCDATASEQ | 卷取阶段全长宽度数据（逗号分隔数值字符串） |

## 12维机理特征（模型输入，服务自动计算，出现在 features_named 中）

6个工艺参数直接取自带钢记录；6个规则标志位由服务按机理逻辑现算（0/1）：

| 特征名 | 含义 |
|--------|------|
| is_FM | 精轧是否有波谷 |
| is_RM | 粗轧是否有波谷 |
| is_DM | 卷取是否有波谷 |
| is_HT | 精轧粗轧波谷位置是否同时在头部或尾部 |
| is_WS | 带钢中部宽度是否不均匀 |
| is_NA | 精轧和卷取宽度是否整体分布均匀且小于精轧目标宽度 |

## 根因知识模板（解释诊断结果时使用）

| 缺陷类型 | 根因 | 检查项 |
|----------|------|--------|
| 卷取拉钢 | 卷取咬入/脱离时张力突变 | 检查卷取机张力闭环响应 |
| 整体宽 | 自然宽展偏差或PDI不当 | 侧导板开口度设定 |
| 整体窄 | 自然宽展偏差或PDI不当 | 侧导板开口度设定 |
| 楔形 | 横向不均匀延伸 | 两侧辊缝对称性 |
| 没有拉钢 | 轧制过程正常 | 复核确认即可 |
| 粗轧头尾 | 短行程控制不合理 | 粗轧头尾SSC策略 |
| 精轧拉钢 | 活套张力控制不稳定 | 精轧机架间活套 |
